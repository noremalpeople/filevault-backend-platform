# F5 安全审查

审查基线为 `8c17b41`。F5 在原有 Windows 单实例、Java 21、Spring Boot、MyBatis、MySQL 和 Vue 架构上修复以下问题。

| 检查项 | F5 结果与证据 |
|---|---|
| 静态目录隔离 | `WebRoot` 解析真实路径并检查交集，`StaticWebConfig` 只公开 Vue 入口与资产。启动拒绝测试、Windows Junction 文件访问测试及浏览器验收均覆盖静态路由。 |
| 所有权、会话和 CSRF | 真实 MySQL 集成套件验证匿名私有下载、缺失或错误 CSRF，以及跨账号文件、上传会话和分享管理拒绝。 |
| 非法文件名和内容 | 保留服务端 UUID 存储键及路径校验。已测路径遍历、文件名与格式拒绝、Windows Junction。PDF 和图片只做文件头辨识。 |
| 分片与并发 | 已测磁盘缺失、同长度内容损坏、幂等补传、异内容冲突、错误 SHA-256、并发完成、上传中止竞争和服务重启续传。 |
| 对账与补偿 | 已用真实数据库和文件验证回滚清除本次新物理对象、双向异常识别、候选宽限及只读扫描。 |

现有服务默认绑定回环地址。若另行公开部署，需要验证认证和匿名下载限流、TLS、Cookie 安全属性、分享路径日志脱敏，以及运维对私有存储的访问控制。已有大小校验、扩展名白名单和文件头检查；内容扫描及历史对象全量校验仍待实现。
