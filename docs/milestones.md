# 里程碑

| 阶段 | 交付范围 |
|---|---|
| F0 通过 | Windows 原生启动、Flyway 迁移、应用与数据库健康检查 |
| F1 通过 | 会话认证、用户隔离、小文件上传与管理 |
| F2 通过 | 上传会话、分片续传、流式合并与清理 |
| F3 通过 | 同用户去重、限时分享与撤销 |
| F4 通过 | Vue 界面、完整浏览器验收、可复现基准测试 |
| F5 通过 | 静态目录隔离、破损分片恢复、短事务、只读存储对账和真实 MySQL 回归 |
| F6 通过 | 跨页前缀搜索、Caffeine 文件统计、持久化只读巡检和有界线程池 |
| F7 通过 | 结构化日志、请求追踪、受保护指标、入口限流、单区间下载与传输实测 |
| F8 本地通过 | README、GitHub Actions、技能证据、简历描述、面试指南。托管 CI 待发布后运行 |

F0 验收使用 Corretto 21.0.13.1、Maven 3.9.11、Spring Boot 4.1.2、MyBatis Starter 4.1.0、MySQL 8.4.13、Node 24.19.0、npm 11.17.0。Windows 上的 MySQL 便携二进制在含中文的绝对数据路径启动时出现路径解析和权限错误。改用独立的 ASCII 路径 `%TEMP%\FileVault-native-20261119\data` 后成功，现有项目数据库未参与。

F1 实现 10 MiB 以内的文件管理。真实 HTTP 测试用两个生成账号验证访问边界，并比对上传、下载和服务端记录的 SHA-256。

F2 验证 14,541,840 字节 CSV 四片上传。提交前两片后实际重启后端，重新登录查到已传索引，补齐分片后原样下载。并发重复完成返回同一文件 ID。

F3 通过真实 MySQL 验证同一用户的相同内容复用物理对象，另一用户上传相同字节使用独立实例。测试了匿名分享、撤销、过期、文件软删除和令牌摘要持久化。

F4 通过 Vue 类型检查和生产构建，使用本机 Chrome、实际 Spring Boot 和原生 MySQL 验证用户操作，并记录 3 次本机分片上传实测。复现命令见 [测试](tests.md) 和 [性能记录](benchmark.md)。

F5 在现有 `filevault_dev` 应用 V5 迁移，增加终止校验失败的状态和清理重试时间。验收使用独立测试目录和随机数据库样例账号。此前基准结果仍归属于 F4。
