# 安全边界

服务和数据库绑定本机回环地址。敏感设置、生成的凭据、数据库文件和运行日志放在 Git 忽略的本地路径。Flyway 开发账号仅授权本项目库。Actuator 只公开健康总状态。

F1 使用 Spring Security 的 BCrypt 委托编码器、HttpOnly / SameSite=Strict 的同源 Cookie 和 CSRF 检查。认证后每个文件查询都按当前用户过滤。文件名仅用于显示和下载头，物理文件使用服务端 UUID，并检查目录真实路径。仅允许 PDF、UTF-8 文本、Markdown、CSV、PNG、JPEG，按格式核对文件头或 UTF-8 内容，下载强制附件且禁止 MIME 嗅探。此检查只判断文件格式，尚未接入恶意软件扫描。

小文件上限 10 MiB，单用户对象配额 512 MiB。软删除保留物理对象并继续占用配额。对象写入后提交数据库，事务确认回滚时清理该对象。进程异常退出可留下孤立对象，F1 尚未自动回收。运行时目录应只授权给应用和本机管理员。
