# 安全边界

服务和数据库绑定本机回环地址。敏感设置、生成的凭据、数据库文件和运行日志放在 Git 忽略的本地路径。Flyway 开发账号仅授权本项目库。Actuator 只公开健康总状态。

F1 使用 Spring Security 的 BCrypt 委托编码器、HttpOnly / SameSite=Strict 的同源 Cookie 和 CSRF 检查。认证后每个文件查询都按当前用户过滤。文件名仅用于显示和下载头，物理文件使用服务端 UUID，并检查目录真实路径。仅允许 PDF、UTF-8 文本、Markdown、CSV、PNG、JPEG，按格式核对文件头或 UTF-8 内容，下载强制附件且禁止 MIME 嗅探。此检查只判断文件格式，尚未接入恶意软件扫描。

小文件上限 10 MiB，单用户对象默认配额 512 MiB，可通过 [资源限制配置](reliability.md#可调资源限制) 调整。软删除保留物理对象并继续占用配额。对象写入后提交数据库，事务确认回滚时尝试清理新建对象。进程异常退出可能留下孤立对象，可通过只读对账检查。运行时目录应只授权给应用和本机管理员。

每用户默认最多 4 个未过期上传会话。分片落盘与合并都按字节上限流式处理，完成时重新计算全文件 SHA-256，再核对格式。启用上传清理调度时，计划任务将到期会话标记为 EXPIRED，并回收已关闭会话的分片。运行目录和数据库应一起备份。异常断电发生在磁盘移动与事务提交之间时，仍可能留下未登记的物理对象，需通过对账处理。

F3 每次上传都接收并校验真实字节后，在同一账户的 READY 对象中匹配 SHA-256 和大小。即使不同账户提交相同内容，数据库和磁盘仍分别登记。分享令牌来自 32 字节安全随机数，服务端存储 SHA-256 摘要，创建时返回一次。公开下载禁止缓存，设置附件、禁止 MIME 嗅探和禁止引用来源。配置反向代理时应对分享路径实施访问日志脱敏。

F5 禁用 Spring 的通配静态映射，只暴露 Vue 入口和资产路由。启动时解析配置中的真实目录，重叠、父子包含和借助符号链接或 Windows Junction 的重叠均被拒绝。静态资源处理器还检查资产自身的实际路径，阻止嵌套目录通过链接离开资产目录。文件存储根仍需限制本机写权限。

应用当前以本机回环演示为部署范围。F7 增加固定窗口限流和带密钥的指标访问。公网部署前仍需单独验收 TLS、Secure Cookie、代理和限流部署、数据备份和审计日志。只读存储扫描输出计数，保留数据库和磁盘现状。[安全审查](security-audit.md) · [运维接口](operations.md)
